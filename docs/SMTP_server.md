# Server SMTP

## Provider di Posta Nazionali e Webmail Italiane

Se possiedi già una casella di posta elettronica con uno di questi gestori, i loro server SMTP utilizzano ancora l'autenticazione classica (indirizzo email + password standard della casella), a patto che non sia stata attivata manualmente la verifica in due passaggi.

| Provider      | Supporto   | Server SMTP        | Porta | Sicurezza | Credenziali richieste                     |
| ------------- | ---------- | ------------------ | ----- | --------- | ----------------------------------------- |
| Aruba         | Verificato | smtps.aruba.it     | 465   | SSL       | Tua WebEmail Aruba + Tua password normale |
| Libero Mail   | ?          | smtp.libero.it     | 465   | SSL       | Tua email Libero + Tua password normale   |
| Virgilio Mail | ?          | smtp.virgilio.it   | 465   | SSL       | Tua email Virgilio + Tua password normale |
| Tiscali       | Verificato | smtp.tiscali.it    | 465   | SSL       | Tua email Tiscali + Tua password normale  |
| Fastweb       | ?          | smtp.fastwebnet.it | 465   | SSL       | Tua email Fastweb + Tua password normale  |
